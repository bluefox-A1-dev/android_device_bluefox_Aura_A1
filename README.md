# Device tree for BLUEFOX Aura A1

The BLUEFOX Aura A1 (codenamed **"Aura_A1"**) is a MediaTek Helio G100 device
that shipped with Android 16.

This repository contains the device configuration for **LineageOS 23.2**.

## Device specifications

| Feature | Specification |
| --- | --- |
| Manufacturer | BLUEFOX |
| Model | Aura A1 (BF00A) |
| Codename | Aura_A1 |
| SoC | MediaTek Helio G100 (MT6789) |
| Architecture | ARM64, with 32-bit application support |
| RAM | 8 GB |
| Storage | 128 GB UFS |
| Display | 720 × 1600 pixels |
| Shipped Android version | Android 16 |
| Kernel | Linux 6.12.69 |
